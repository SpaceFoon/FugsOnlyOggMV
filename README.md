# Fugs Only OGG MV

Use OGG audio throughout RPG Maker MV deployments without maintaining a duplicate M4A audio library.

| | |
|---|---|
| **Version** | 1.0.0 |
| **Engine** | RPG Maker MV 1.6.x |
| **Plugin file** | `FugsOnlyOggMV.js` |
| **License** | MIT ([LICENSE](LICENSE)) |

- [Repository](https://github.com/SpaceFoon/FugsOnlyOggMV)

## Install

1. Copy `FugsOnlyOggMV.js` into your game's `js/plugins/` folder.
2. Enable **FugsOnlyOggMV** in RPG Maker MV's Plugin Manager.
3. Keep your audio files in OGG format. The plugin has no parameters.

## What it changes

The plugin makes RPG Maker MV resolve audio files with the `.ogg` extension for all deployments. It does not convert audio files; provide OGG files in your project.
